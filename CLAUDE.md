# Instrucciones para Claude Code en este repo

Las instrucciones de trabajo son comunes a todos los agentes de IA y viven en
`AGENTS.md`: orden de lectura obligatorio, doctrina transversal del ente
(repo de gobernanza `ia_nest_meta`), disciplina de versionado y modo ciego.

Leelo antes de proponer o valorar cualquier cambio de diseno. No se duplica
aqui: si este documento y `AGENTS.md` divergen, manda `AGENTS.md` (hogar unico,
meta ADR 0008).

Lo unico propio de Claude Code:

- Los documentos del repo van sin acentos ni tildes. Es convencion deliberada
  del proyecto (`ia_nest_meta/docs/CONVENCIONES_TRANSVERSALES.md`), no una
  errata que corregir.
